# Support

## How to get help

1. **Docs** — start with the [README](README.md) and the numbered guides under [`docs/`](docs/).
2. **Wiki / Pages** — contributor and usage guides in [`docs/wiki/`](docs/wiki/) (also published via GitHub Pages when enabled).
3. **Discussions** — questions and ideas belong in
   [GitHub Discussions](https://github.com/ao3575911/glossa/discussions).
4. **Issues** — use the labelled templates for bugs, features, docs, and performance.

## What we do not offer

- Private consulting or guaranteed SLA for free community support
- Debugging private or copyrighted corpora shared in public channels
- Security triage via public issues (use [SECURITY.md](SECURITY.md))

## Project status

Glossa is early (Stage 0–1): workspaces, import, positional index, and KWIC.
Later stages (TUI, stats, plugins) are stubbed — see the PRD and build spec.
