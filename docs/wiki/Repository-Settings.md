# Repository settings

Desired configuration is recorded in [`.github/settings.yml`](https://github.com/ao3575911/glossa/blob/main/.github/settings.yml). Apply manually or via the [repository-settings](https://github.com/repository-settings/app) GitHub App.

## Checklist

- [ ] **Discussions** enabled (`has_discussions: true`)
- [ ] **Wiki** enabled (content sourced from `docs/wiki/`)
- [ ] **Projects** enabled; create **Glossa delivery** board (`docs/projects.md`)
- [ ] **Pages** source = GitHub Actions (`Pages` workflow)
- [ ] **Private vulnerability reporting** enabled
- [ ] **Secret scanning** + push protection enabled
- [ ] Branch protection on `main` with required CI + quality checks
- [ ] Squash merge preferred; delete head branches on merge
