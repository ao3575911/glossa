Contributing handbook

Short companion to CONTRIBUTING.md.

Labels

Synced from .github/labels.yml:

  • type: bug feature docs chore refactor performance security question ci
  • area: crate or concern (cli, index, nlp, …)
  • priority / status / size: planning
  • pr: breaking dependencies ready draft do-not-merge

Issue templates apply type:* and status:triage. PR paths are auto-labelled.

Discussions

Enable Discussions in repository settings, then use:

  • Ideas — proposals
  • Q&A — questions
  • Show and tell — workflows and demos

Agents

Coding agents should follow AGENTS.md: read the PRD/spec first, keep stages scoped, verify with fmt/clippy/test.

Seed issues

Maintainers: Actions → Seed labelled issues (set dry-run to false) after labels sync.
