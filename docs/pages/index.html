glossa

Every linguist’s research tool, in one fast terminal workspace.

Offline-first CLI for corpora, positional indexes, and KWIC — built in Rust.

Repository Wiki Discussions

Start

Install from source, initialise a workspace, import text, run concordance.

cargo install --path crates/glossa-cli
glossa init my-project && cd my-project
glossa corpus add ./texts --name demo
glossa kwic Alice --corpus demo --sort R1
