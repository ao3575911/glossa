# Executive statement

Linguistic research is fragmented: a typical project moves text through a concordancer (AntConc or Sketch Engine), a parser (spaCy, Stanza or UDPipe), a phonetics app (Praat), an annotation tool (ELAN or FLEx), and R or Python for statistics, with hand-rolled glue scripts in between that rarely get recorded well enough to reproduce. Glossa replaces the glue with one fast, offline, cross-platform binary in which every analysis is both a TUI screen and a scriptable command with JSON output, sharing one project workspace, one corpus index and one reproducible session log that can generate a methods section and BibTeX. The timing is right: Universal Dependencies now covers well over 100 languages, ONNX makes neural taggers portable without a Python runtime, Rust TUI tooling (ratatui) is mature, and reproducibility expectations from journals and funders keep rising. Impact: hours saved per project on format conversion and glue code, analyses that can be re-run exactly from a log, and a free, offline toolkit usable in the field and in low-bandwidth institutions.
